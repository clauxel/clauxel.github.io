What MiroFish is for

MiroFish is useful when a decision depends on how different actors might react over time. Instead of asking for one flat answer, a run starts with source material, builds graph context, prepares agent personas, runs interaction rounds, and returns a structured report for review.

Use it as decision support: it can expose plausible reactions, weak assumptions, and follow-up questions, but important claims still need real evidence or accountable review.

Source repository Repository homepage Static demo
SeedStart with a question, report, notes, or files that define the scenario boundary.
GraphExtract entities, relationships, constraints, signals, and assumptions.
AgentsCreate roles with motives, memory, and different positions inside the scenario.
RoundsLet agents react, disagree, update, and surface branches that need review.
ReportRead the scenario report, then ask follow-up questions before acting.

Where should I start with MiroFish?

Start at mirofish.work if you want a hosted product route, then use the tutorial and workflow pages when you need a narrower explanation.

Is MiroFish a guaranteed forecast?

No. Treat MiroFish output as scenario rehearsal and decision support. Use the report to find assumptions, branches, and validation steps before making a consequential decision.

Which pages are included here?

Every HTML page found in the current MiroFish.work sitemap snapshot is included. Image assets are not listed as pages, though the product image is used above as a visual reference.

What about source code?
